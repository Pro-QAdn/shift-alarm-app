# ShiftAlarm Android App (Робоча назва)
Мобільний додаток для Android, створений для вирішення проблеми складних змінних графіків (комбінація нічних та ранкових підйомів через день / за циклом), з якими не справляються стандартні системні годинники.
## 📋 Технічне завдання (ТЗ)
1. **Інтеграція з системним будильником Android (`AlarmManager`):**
* Додаток керує системними будильниками пристрою напряму через програмні API, гарантуючи гучний і надійний сигнал у потрібний час.
2. **Візуальний календар, ручне налаштування та Простий будильник:**
* Перегляд розкладу в зручному форматі календаря.
* Можливість ручного коригування часу на будь-який день.
* **Режим «Простий будильник»:** швидке створення звичайного одноразового будильника на потрібний час (як у стандартному годиннику).
3. **Шаблони змінного графіку (Паттерни):**
* Автоматична генерація розкладу наперед за цикличною схемою (наприклад: *Ніч 23:45 ➔ Вихідний ➔ Ранок 06:00 та Ніч 23:45*).
4. **Автоматичне очищення старих будильників:**
* Автоматичне видалення з системи минулих і спрацьованих будильників для запобігання захаращенню пам'яті телефону.
5. **Кнопка форс-мажору («Змінити сьогодні»):**
* Швидкий елемент керування на головному екрані для миттєвого скасування або додавання позапланового підйому на поточний день.
6. **Резервна страховка (Push-сповіщення):**
* Захист від закриття фонових процесів агресивними енергозберігаючими механізмами ОС Android (Xiaomi, Samsung тощо).
---
## 🛠 Архітектура та Модулі (План розробки)
* **`AlarmManagerModule`** — взаємодія з системним планувальником Android для встановлення та скасування будильників.
* **`PatternEngine`** — логіка генерації дат і часу на основі заданого циклично-змінного шаблону.
* **`CalendarUI`** — інтерфейс користувача для візуалізації графіка та ручного редагування.
* **`ForegroundService / Watchdog`** — фонова служба для забезпечення надійності роботи додатку та відправки резервних сповіщень.
