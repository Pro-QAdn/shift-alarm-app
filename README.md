# ShiftAlarm Android App (Робоча назва)
Мобільний додаток для Android, створений для вирішення проблеми складних змінних графіків (комбінація нічних та ранкових підйомів через день / за циклом), з якими не справляються стандартні системні годинники.
## 📋 Технічне завдання (ТЗ)
1. **Інтеграція з системним будильником Android (`AlarmManager`):**
* Додаток керує системними будильниками пристрою напряму через програмні API, гарантуючи гучний і надійний сигнал у потрібний час.
* Точне спрацювання через AlarmManager із відповідним режимом для будильника.
* Відтворення сигналу через власний механізм звуку, а не залежність від стандартного «Годинника».
* Можливість вимкнути сигнал і відкласти його на заданий час.
* Відновлення розкладу після перезавантаження телефону.
Перевірка дозволів і зрозуміле попередження, якщо Android не дозволяє запланувати точний будильник.
2. **Візуальний календар, ручне налаштування та Простий будильник:**
* Перегляд розкладу в зручному форматі календаря. (Місячний календар - Кольорові позначення: нічна зміна, ранкова зміна, вихідний, ручна зміна, будильник вимкнений. Час підйому відображається прямо в комірці дня.)
* Головний екран - Великий час наступного підйому, дата, тип зміни, статус системного будильника та швидкі кнопки керування.
* Можливість ручного коригування часу на будь-який день.
* Ключові можливості:
- Власна назва шаблону.
- Дата початку циклу — обов'язкова точка відліку, щоб цикл не зсувався.
- Попередній перегляд згенерованого графіка на 30, 60 або 90 днів.
- Застосування шаблону до вибраного діапазону дат.
- Окремі винятки для свят, відпусток, чергувань та інших змін.
- Копіювання готового шаблону.
* **Режим «Простий будильник»:** швидке створення звичайного одноразового будильника на потрібний час (як у стандартному годиннику).
* При ручному зміненні часу на конкретний день застосунок повинен запитувати, чи це разовий виняток, чи зміна всього шаблону. Інакше можна випадково зіпсувати весь цикл.
3. **Шаблони змінного графіку (Паттерни):**
* Автоматична генерація розкладу наперед за цикличною схемою (наприклад: *Ніч 23:45 ➔ Вихідний ➔ Ранок 06:00 та Ніч 23:45*).
4. **Автоматичне очищення старих будильників:**
* Автоматичне видалення з системи минулих і спрацьованих будильників для запобігання захаращенню пам'яті телефону.
* зберігати історію, а не просто видаляти
  розділити:
- Розклад — усі заплановані підйоми.
- Системні сигнали — лише ті будильники, які потрібно передати Android для виконання.
- Історія — минулі спрацювання, скасування та зміни.
5. **Кнопка форс-мажору («Змінити сьогодні»):**
* Швидкий елемент керування на головному екрані для миттєвого скасування або додавання позапланового підйому на поточний день.
* бов'язкова логіка: зміна сьогоднішнього будильника не повинна непомітно змінювати наступні дні циклу. Якщо користувач скасував сигнал, застосунок має показати це явно, а не залишати враження, що підйом усе ще запланований.
Для скасування особливо важливого сигналу можна додати підтвердження. Але не варто робити зайві діалоги для звичайної зміни часу.
6. **Резервна страховка (Push-сповіщення):**
* Захист від закриття фонових процесів агресивними енергозберігаючими механізмами ОС Android (Xiaomi, Samsung тощо).
* Основний будильник — локальний точний сигнал Android.
-Резервний сигнал — окреме локальне сповіщення, заплановане заздалегідь.
-Контроль стану — перевірка дозволів, активності майбутніх сигналів і доступності повноекранного сповіщення, якщо воно використовується.
-Відновлення — повторне планування після перезавантаження, оновлення часу або часового поясу.
-Діагностика — попередження, якщо резервний механізм не налаштований.
7. Майбутьне
7. Що ще я б додав
Ось функції, 
Поступове посилення сигналу
Будильник починає з тихішого рівня та поступово збільшує гучність, якщо це підтримує реалізація. Окремо — можливість відключити цю функцію.
Кілька сигналів на один підйом
Наприклад, основний о 05:30 і додатковий о 05:40. Це окремі будильники, а не звичайне відкладення, яке можна випадково забути активувати.
Незалежні налаштування звуку
Вибір мелодії, вібрація, тривалість сигналу, поведінка при натисканні кнопок гучності та тест відтворення. Варто окремо врахувати режим «Не турбувати».
Резервна копія графіка
Експорт та імпорт шаблонів і винятків у файл. Після перевстановлення застосунку або зміни телефону не доведеться відновлювати весь цикл вручну.
Індикатор готовності
На головному екрані видно, чи є дозвіл на точні будильники, чи запланований наступний сигнал і чи налаштовані резервні механізми. Це корисніше, ніж просто зелений перемикач «Увімкнено».

## 🛠 Архітектура та Модулі (План розробки)
* **`AlarmManagerModule`** — взаємодія з системним планувальником Android для встановлення та скасування будильників.
* **`PatternEngine`** — логіка генерації дат і часу на основі заданого циклично-змінного шаблону.
* **`CalendarUI`** — інтерфейс користувача для візуалізації графіка та ручного редагування.
* **`ForegroundService / Watchdog`** — фонова служба для забезпечення надійності роботи додатку та відправки резервних сповіщень.
* Schedule Engine	Генерація циклів, обробка винятків, розрахунок дат і часу
Alarm Scheduler	Створення, оновлення та скасування системних сигналів
Alarm Receiver / Sound	Реакція на спрацювання, запуск звуку, вимкнення та відкладення
UI + Database	Календар, налаштування, шаблони, історія та резервні копії
